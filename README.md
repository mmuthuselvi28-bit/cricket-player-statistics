# Cricket Player Statistics App

## Project Description

The Cricket Player Statistics App is a simple web application that displays cricket player performance statistics. Users can search for a player and view their statistics in an easy-to-understand format.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Player statistics display
* Player search functionality
* Responsive design
* Simple user interface
* Player performance cards
* Mobile-friendly layout

## Statistics Included

### Batsmen

* Matches
* Runs
* Average
* Centuries
* Strike Rate

### Bowlers

* Matches
* Wickets
* Average
* Economy
* Best Bowling

## How to Run

1. Open the project folder in **VS Code**.
2. Open `index.html`.
3. Paste the HTML, CSS, and JavaScript code.
4. Save the file.
5. Right-click `index.html`.
6. Select **Open with Live Server**.
7. The Cricket Player Statistics App will open in your browser.

## How It Works

1. Player information is displayed as cards.
2. Enter a player name in the search box.
3. Click the **Search** button.
4. The matching player's statistics will be displayed.
5. The layout automatically adjusts for mobile devices.
